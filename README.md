# be-was-2025
코드스쿼드 백엔드 교육용 WAS 2025 개정판

## Step 7 : 게시판 기능 완성

### 기능요구사항

글쓰기 기능 구현 (5pt)
- [ ] main/index.html에 글쓰기 버튼 추가 
- [ ] 로그인한 사용자가 글쓰기 버튼을 누르면 article/index.html로 이동 
- [ ] 로그인 하지 않은 사용자가 글쓰기 버튼을 login/index.html로 리다이렉트
- [ ] main/index.html에 제목 표시

### 프로그래밍 요구사항

- 404 및 기타 에러 처리 (5pt)
  - [ ] 존재하지 URL은 404 페이지로 이동하도록 구현
  - [ ] 처리할 수 없는 요청 메서드도 에러 페이지로 이동하도록 구현
  - [ ] 기타 서버 오류를 확인할 수 있는 에러 페이지로 이동하도록 구현

- DB 연동 (5pt)
  - [ ] H2와 JDBC를 사용하여 회원정보와 게시글을 저장하도록 구현
